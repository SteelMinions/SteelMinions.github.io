# Summary:
This changelog documents a major website redesign for Steel Minions, implementing a modern feature-section layout inspired by the Satisfactory game website while maintaining Steel Minions' color scheme and comprehensive WCAG AA accessibility standards. The session included header modernization with Bootstrap 5, carousel responsive styling, and application of the new layout pattern to multiple pages.

Full list of changes is as follows:

## Added:

### CSS Styling (css/styles.css):
- Feature-section layout styling:
  - `.feature-section` class with padding, margin, and responsive container styling
  - `.feature-container` with flexbox gap (60px) for alternating left-right layout
  - `.feature-reverse` class for reversing flex direction on alternate sections
  - `.feature-content` and `.feature-placeholder` for content organization
  - `.feature-title` (h2) and `.feature-text` (p) typography classes
  - `.placeholder-content` for sidebar content boxes

- Carousel responsive styling:
  - `.carousel` with max-width scaling (600px mobile, 600px tablet, 800px desktop, 900px large)
  - `.carousel-inner` with aspect-ratio (1080/1350) and responsive min-height
  - `.carousel-item` full-width, full-height image display
  - Responsive carousel indicators and controls (44-52px sizing by breakpoint)

- Accessibility standards implementation:
  - Focus outlines: 3px solid with 2px offset on all interactive elements
  - Touch target sizing: 44px on mobile, 48px on tablet, 52px on desktop for buttons/controls
  - Button accessibility: min-width, min-height, focus states
  - Form input styling: 44px+ min-height with focus outlines
  - Color contrast: White text (#FFFFFF) on dark backgrounds for WCAG AA (4.5:1+)
  - Smooth transitions on all interactive elements

- Contact page specific styling:
  - `.contact-info` grid layout (auto-fit columns, 250px minimum)
  - `.contact-item` with gradient borders and semi-transparent background
  - `.contact-label` and `.contact-value` typography
  - `.contact-link` with hover and focus states (blue #4c9eec, orange #ED5128 on hover)
  - Accessible link styling with proper focus indicators

- Feature list styling:
  - `.feature-list` with no bullets, proper spacing
  - `.feature-list li` with bottom border separator and responsive font sizing
