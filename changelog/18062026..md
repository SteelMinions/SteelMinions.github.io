# CHANGELOG 18/06/2026 | Developer Branch

# Title: Homepage Card System, Multi‑Item Carousel Upgrade, Portfolio Content Update, and About Page Modernisation

### Version 2.2

### Date: 2026-06-18

### Author: Matthew Ryan Dudley

# Time: 08:00 BST – 16:00 BST

# Summary:

This changelog documents major improvements across the Steel Minions website, including new dynamic homepage cards, upgraded multi‑item carousels, updated portfolio content for _The Chantry_, and a full modernisation pass on the **About Us** page to align it with the new feature‑section layout.  
Additional fixes include consistent carousel sizing, corrected include‑load timing, and improved readability for informational sections.

Full list of changes is as follows:

---

## Added:

### Cards System (indexCards.js)

- Added new homepage cards for:
  - **Piecefall**
  - **Racecar Crashers**
  - **The Chantry**
- Implemented fully clickable card wrappers using `<a>` tags.
- Added responsive Bootstrap grid layout for cards.
- Introduced future‑proof structure for adding new cards.

### Carousels (customCarousels.js)

- Added **multi‑item carousel support** for:
  - `#theChantry-carousel`
  - `#rcc-carousel`
  - `#piecefall-carousel`
- Added responsive behaviour:
  - 3 items on desktop
  - 2 items on tablet
  - 1 item on mobile
- Added delayed initialisation to ensure carousels load after HTML includes.
- Added automatic resizing and slide event listeners.

### Portfolio Content (The Chantry)

- Added new poster and gameplay images:
  - `theChantry_poster.webp`
  - `theChantry_gply1.webp`
  - `theChantry_gply2.webp`
  - `theChantry_gply3.webp`
- Added new descriptive text and updated game details.
- Updated portfolio section to match new feature‑section layout.

### About Page Modernisation

- Converted **About Us**, **Course Links**, and **Finances** sections to the new feature‑section layout.
- Added new `.feature-list-clean` class for clean bullet lists without separators.
- Improved readability, spacing, and structure across all informational sections.
- Ensured consistent typography using `.feature-title` and `.feature-text`.

### JS Cards SOP Documentation
- Added new SOP documentation for the card system, detailing requirements, HTML structure, and JavaScript file structure.

### JS Carousels SOP Documentation
- Added new SOP documentation for the multi‑item carousel system, detailing requirements, HTML structure, and JavaScript file structure.

## Changed:

### portfolio.html

- Updated The Chantry section with new images, text, and layout.
- Updated Piecefall and RCC sections to remove incorrect wrapper IDs.
- Improved carousel include structure for consistency.
- Ensured all carousels use the correct root IDs inside include files.

### about.html

- Rewrote About Us and Course Links sections for clarity and readability.

- Updated lists to use `.feature-list-clean` for improved visual clarity.
- Improved spacing, alignment, and typography.

- Reintroduced consistent carousel sizing using:

- Adjusted margins and padding for consistent layout across pages.

### customCarousels.js

- Replaced early initialisation with delayed load‑safe initialisation.
- Added retry logic to ensure carousels load after HTML includes.
- Improved stability of multi‑item logic across all breakpoints.

### SOP Documentation
- Added new sections for JS Cards and JS Carousels SOPs.
- Updated existing SOP documentation to include new file structures and requirements.
